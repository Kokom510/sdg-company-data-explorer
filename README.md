# SDG Impact Scorecard

SDG Sector Impact Scoring Model to assess a potential or existing investment company's contribution to the UN Sustainable Development Goals (SDGs), scored against the sector-relevant targets and indicators of a chosen framework.

## Streamlit Cloud entrypoint

`streamlit_app.py`

## Dependencies

`requirements.txt`

## Important

This prototype uses public web search results and accessible web pages. Its 0–100 SDG values are keyword/evidence research proxies, not official SDG ratings.

For a production investment/ESG scorecard, add sector-specific expectations, quantitative KPIs, source-page references, reporting periods, analyst review, and an audit trail.
